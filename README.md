# Демо ТРЦ «Планета» в Перми

Демо новой десктопной сетки на трёх страницах. Оно использует HTML и CSS [главной страницы стенда](https://stage-frontend-leto.planeta-mall.ru/), его шрифт и медиа. Поиск фильтрует разделы и карточки из локального снимка. Остальные ссылки ведут на стенд.

- [Главная на GitHub Pages](https://zhenchur.github.io/planeta-layout-demo/)
- [Вакансии](https://zhenchur.github.io/planeta-layout-demo/vacancies/)
- [Новость о прокате колясок](https://zhenchur.github.io/planeta-layout-demo/news/article_95088/)

Пароль проверяется в браузере. После ввода доступ сохраняется до конца сеанса вкладки. Исходники и медиа доступны по прямым ссылкам.

## Запуск

```sh
node server.mjs
```

Откройте [127.0.0.1:4173](http://127.0.0.1:4173/). Установка зависимостей не требуется.

Статическая сборка для GitHub Pages создаётся командой `node build.mjs --base /planeta-layout-demo/`. Готовые файлы появляются в `dist/`.

## Где править

- `public/index.html` — разметка главной.
- `public/pages/` — содержимое внутренних страниц.
- `public/styles/shell-layout.css` — общая сетка, размеры обложки и состояние шапки при прокрутке.
- `public/styles/` — стили и адаптивные правила.
- `public/hero.js` — вкладки и карточки первого экрана.
- `public/shell.js` — шапка, меню и поиск.

## Адаптивность

| Размер в Chrome | Поведение |
| --- | --- |
| 1440 × 900 px | Обложка 4:3 по центру области без правой навигации. Поиск начинается на её левом краю и заканчивается у правой колонки. |
| 820 × 900 px | Планшетная шапка с отступами, стопка карточек и футер ниже. Корневой размер шрифта 11,389 px. |
| Ширина 390 px | Логотип по центру, стопка карточек со свайпом, вкладки под ней. Корневой размер шрифта около 10 px. |

Основные переходы в CSS на 720 и 1024 px. Футер главной появляется от 720 px, фиксированная правая навигация от 1024 px. Фон страницы переходит на планшетный от 920 px. При ширине до 1023 px в альбомной ориентации стенд предлагает повернуть экран. Корневой размер шрифта задан в `vw` до 1920 px, затем фиксируется на 10 px.

На десктопе кадр занимает высоту окна за вычетом шапки и нижнего отступа. Целевая пропорция 4:3 сохраняется, если хватает ширины. На узком высоком экране кадр становится уже, а фото заполняет его с обрезкой по краям. В низком окне карусель уменьшает внутренние отступы, а при достижении минимальной высоты кадра доступна прокрутка страницы.

Правая колонка использует тот же внешний отступ, что и шапка и кадр. В низком окне список прокручивается между шапкой и нижним отступом. При прокрутке страницы меняется фон шапки и контраст логотипа и поиска. Размеры и положение контролов остаются прежними.

## Сверка с требованиями

Сверены два источника: клиентский DOCX «ТЗ — Верстка основного блока картинки для всех страниц» и пять пунктов о масштабировании, зафиксированных в переписке. Статусы относятся к десктопной демке. Замеры сделаны на шести размерах окна, включая 1921 × 1080, низкое окно 1285 × 285 и узкое высокое 1033 × 903.

| Требование DOCX | Что получилось |
|---|---|
| Правая колонка занимает всю высоту окна | **Выполнено в демке.** Кнопки расположены сверху, меню доходит до нижнего отступа. В низком окне список прокручивается под шапкой. |
| Ширина правой колонки зависит от размеров иконок и шрифта | **Выполнено для текущего масштаба.** Ширина связана с размерами элементов. Новая шкала шире 1920 px ещё не внедрена. |
| Четыре внешних отступа правой колонки равны, меню центрировано | **Выполнено в демке.** В низком окне нижние ссылки доступны прокруткой внутри колонки. |
| Отступы правой колонки, верхний и нижний отступы поиска и высота блока 6 равны | **Выполнено в проверенных окнах.** Замеры совпали с точностью до одного пикселя. |
| Область слева от меню делится на три части. Боковые поля 2 и 3 равны | **Выполнено.** Кадр центрирован в области без правой колонки. |
| Кадр занимает всю доступную высоту за вычетом шапки и блока 6 | **Выполнено в проверенных окнах.** У кадра есть минимальная высота, чтобы карточка и вкладки оставались доступны. Если окно ниже, прокручивается страница. |
| Кадр имеет пропорцию 4:3, ширина рассчитывается от высоты | **Выполнено с исключением.** При достаточной ширине действует 4:3. В узком высоком окне выбрали заполнение высоты и равные боковые поля. Фото кадрируется без растяжения. |
| Поиск занимает всю ширину блока 4 | **Выполнено.** Левый край совпадает с краем кадра, правый доходит до колонки меню, как на схеме. |
| Элементы внутри кадра сохраняют прежние отступы | **Частично.** Где хватает места, отступы сохранены. В низком окне их уменьшили, чтобы карточка и вкладки помещались. |
| Логотип использует общие отступы и вписывается по высоте поиска или доступной ширине | **Выполнено.** При ограничении по высоте логотип центрируется по горизонтали, при ограничении по ширине — по вертикали. |
| При прокрутке появляется белая шапка. Размеры и позиции поиска, логотипа и верхних кнопок сохраняются | **Выполнено по геометрии.** Замеры подтвердили отсутствие сдвига. Для читаемости на белом фоне также меняется цвет логотипа и оформление поиска. |
| Общая вёрстка применяется на всех страницах | **Частично.** Она подключена на главной, в «Вакансиях» и на странице новости. |

| Пункт из переписки | Что получилось |
|---|---|
| **1.** Дизайн главной на 2560 × 1080, 2560 × 1440 и 3840 × 2160 при масштабе 100% | **Не выполнено.** Отдельной проработки главной для этих размеров не было. В DOCX конкретные разрешения не заданы. |
| **2.** Новая логика масштабирования шире 1920 px | **Не выполнено.** С 1920 px базовый размер шрифта фиксируется на 10 px, поэтому шапка, меню и кнопки дальше не масштабируются. |
| **2.** Баннер шире 1920 px без фиксированной пропорции | **Требует уточнения.** DOCX задаёт 4:3 центральному блоку, а договорённость снимает ограничение с баннера. Сейчас баннер заполняет этот блок, и формула даёт 4:3 на всех трёх согласованных разрешениях. |
| **3.** Адаптация меню, баннеров и основных блоков | **Частично.** В демке высота меню и кадра подстраивается под окно. Адаптация компонентов под новую шкалу и её перенос на весь сайт остаются открытыми. |
| **4.** Проверка и корректировка фиксированных размеров иконок и UI | **Частично.** Исправлены отдельные элементы меню и карусели. Полный проход по компонентам на согласованных разрешениях не проведён. |
| **5.** Проверка баннеров и контентной сетки на 20 страницах | **Частично.** В демке проверены главная, «Вакансии» и страница новости. |
| **5.** Проверка в Chrome 145, Firefox 147 и Safari 18 при 100% | **Не выполнено в согласованном объёме.** Замеры демки в браузере есть. Полную проверку в указанных версиях при 100% не проводили. |

Остальные 17 страниц из пункта 5: Развлечения, страница события, Еда, страница ресторана, Магазины, страница партнёра, Новости и акции, Услуги и Сервисы, страница сервиса, О ТРЦ, Подарочная карта, Бонусная карта, Стилист, Фитнес, Аквапарк, Как добраться и Карта ТРЦ.

**Что нужно согласовать:** распространяется ли свободная пропорция баннера на видимую рамку центрального блока при ширине более 1920 px. Если да, для неё на этих ширинах нужно снять правило 4:3 из DOCX. Дизайн для трёх согласованных разрешений, новая шкала размеров и проверка страниц остаются отдельными работами.
